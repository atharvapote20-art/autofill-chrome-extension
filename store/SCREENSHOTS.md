# Screenshot guide — Secure Form Vault

Capture at **1280×800** (preferred) or **640×400**. Use a clean browser window (hide bookmarks bar if possible).

## Shot 1 — Popup (unlock / fill)
1. Open any http(s) page (or the local test form).
2. Unlock the vault.
3. Click the Secure Form Vault toolbar icon.
4. Screenshot the popup showing profile select + **Fill this tab**.

## Shot 2 — Settings / Profiles
1. Open Settings from the popup footer.
2. Go to **Profiles**.
3. Show readable labels (Full name, Email, …) with a few values filled.
4. Screenshot the main dashboard area (rail + profile fields).

## Shot 3 — Fill toast on a real form
1. Open a form page with name/email/address fields.
2. Unlock → Fill this tab (or `Option+Shift+F` / `Alt+Shift+F`).
3. Capture the page with the **top-right toast** (“Filled N fields”) visible.
4. Crop so the toast and a few filled inputs are clear.

## Tips
- Avoid personal real data in screenshots; use fake demo values.
- Don’t include other extension icons that clutter the toolbar if you can help it.
- Export PNGs; upload in the Chrome Web Store listing “Graphics” section.
